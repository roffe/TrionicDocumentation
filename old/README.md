# Old manuals

The T5Suite, T7Suite and T8Suite user manuals as they were before TxSuite, converted from Dilemma's PDFs and checked against them page by page. Kept here so the source material is easy to look at, they're not built into any PDF.

- `t5-manual/`: T5 Suite 2.0 user manual, version 1.6.3
- `t7-manual/`: T7 Suite user manual, V2.2.5
- `t8-manual/`: T8 Suite user manual, 1.3.0

The chapters are numbered in the order of the original. The current manuals are the TxSuite ones, in `txsuite/` and the `t5-manual/`, `t7-manual/`, `t8-manual/` folders in the root.

The original PDFs themselves ship with the old suites and are in the root of [TuningSuites](https://github.com/roffe/TuningSuites).
